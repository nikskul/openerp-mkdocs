# Open ERP

Open ERP - открытый проект ERP (Enterprise Resource Planning).

## Концепция

ERP для предприятия автоматизирующая базовые потребности
бизнеса. Направлена на сокращение затрат на операционную деятельность.

Объединяет в себе:

1. Продажи
2. Закупки
3. Склад
4. Персонал
5. Финансы
6. Отчетность

## Малый и Средний бизнес

Основные объекты автоматизации - операционные процессы малого и
среднего бизнеса в сфере розничной торговли.

Основные процессы для автоматизации:

- Каталог товаров
	- Ведение списка товаров: наименование, артикул, цена, поставщик, категория
- Складской учет
	- Список складов
	- Добавление товаров на склад
	- Учет остатков на складах
- Кадровый учет
	- Ведение списка сотрудников
- Работа с заказами
	- Оформление заказа. Сроки, исполнители, содержание (товары).
