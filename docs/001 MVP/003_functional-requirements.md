# Функциональные требования

## ФТ-1 Аутентификация

- ФТ-1.1 Система должна предоставлять форму входа с вводом Логина и Пароля.

- ФТ-1.2 Система должна обеспечивать независимость от регистра при вводе Логина.
  USER и user одинаковы.

- ФТ-1.3 Система должна считать введенный в форме пароль верным только при полном его
  соответствии сохраненному.

- ФТ-1.4 Система должна обеспечить соответствие любого сохраняемого пароля следующим
  требованиям:
      - длина от 12 до 32 символов (включительно)
	  - не менее 1 заглавнй буквы
	  - не менее 1 строчной буквы
	  - не менее 1 спец. символа

- ФТ-1.5. При вводе неверной пары Логин\Пароль система должна отображать ошибку в
  обезличеной форме: "Неверный логин или пароль" (без уточнения, какая часть не совпала).
  
- ФТ-1.6 Система должна хранить пароль исключительно в зашифрованном виде, без возможности
  обратного расшифрования. При помощи функции, обеспечивающей отвутствие колизий с
  допущением, что пароли не длинее 32 символов.

- ФТ-1.7 Система должна ограничивать число попыток входа 10. После этого учетная запись
  блокируется на 5 минут, всего 30 попыток. Если за 30 попыток не удалось войти, то
  учетная запись блокируется системой до ручной ее разблокировки. При разблокировке
  учетной записи или успешном входе - счетчик сбрасывается.
  
- ФТ-1.8 Передача данных должна происходит по защищенному протоколу.

- ФТ-1.9 Восстановление доступа к учетной записи возможно только через сброс пароля. Сброс
  пароля возможен только с помощью специализированного персонала.
  
## ФТ-2 Авторизация 

- ФТ-2.1 Система должна обеспечивать разделение прав доступа.

- ФТ-2.2 Система должна обеспечивать невозможность просматривать данные, пользователям не
  имеющим прав на просмотр этих данных.
  
- ФТ-2.3 Система должна обеспечивать невозможность изменять данные пользователям, не
  имеющим прав на изменение этих данных.
  
- ФТ-2.4 Система должна запрещать доступ по умолчанию, если подходящее правило
  авторизации отсутствует.

- ФТ-2.5 Система должна проверять права доступа на серверной стороне при чтении и
  изменении защищённых данных.
  
- ФТ-2.6 Система должна учитывать актуальный статус учётной записи при проверке доступа.

## ФТ-3 Управление правами доступа

- ФТ-3.1 Система должна обеспечивать интерфейс для управления правами доступа
  пользователей: создавать, блокировать, назначать права учетным записям пользователей.
  
- ФТ-3.2 Система должна обеспечить доступ к управлению правами пользователей только
  специализированному персоналу.
  
- ФТ-3.3 Система должна фиксировать операции управления учётными записями и правами
  доступа в журнале аудита.
  
- ФТ-3.4. Система должна обеспечивать прекращение доступа заблокированной учётной записи в
  установленный срок.
